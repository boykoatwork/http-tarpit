A high-performance asynchronous HTTP tarpit designed to monitor automated scanning campaigns, collect behavioral data, and implement active defense mechanisms.

This tool complements our [Multi-threaded SSH Honeypot](https://github.com/boykoatwork/honeypot) by providing a lightweight, active-defense layer. While the SSH honeypot captures post-authentication payload delivery, the tarpit focuses on large-scale automated scanning and reconnaissance, providing a broader view of the botnet lifecycle.

## Features

*   **Asynchronous Engine**: Built with `aiohttp` to efficiently handle high-concurrency connections.
*   **Active Defense**: Implements resource exhaustion (tarpit) for traffic matching anomalous patterns (e.g., directory brute-forcing, injection attempts).
*   **Forensic Logging**: Captures detailed HTTP metadata, including full headers, User-Agent, and session duration.
*   **GeoIP Enrichment**: Integrated MaxMind GeoLite2 support for real-time ASN and geographic mapping.
*   **Structured Storage**: SQLite-backed architecture for reliable data persistence and query analysis.


## Data Usage & Research

This project generates structured datasets that are well-suited for threat intelligence research, botnet activity analysis, and behavioral classification studies. The generated `tarpit_events.db` supports complex SQL queries to identify scanning trends, injection attempts, and geographical distribution of malicious actors.

The dataset generated by this tarpit (including raw traffic, forensic sanitization artifacts, and behavioral slices) is available on Zenodo:

[DOI: 10.5281/zenodo.19631120](https://doi.org/10.5281/zenodo.19631120)

All published datasets are pre-processed to ensure high forensic fidelity. This includes IP address sanitization (handling proxy forwarding artifacts) and the exclusion of operational reporting metadata to provide a clean, noise-free research artifact.

### Reporting Policy & Data Integrity

The project includes an integrated module for reporting suspicious IPs to [AbuseIPDB](https://www.abuseipdb.com/).

This module operates without ASN-based whitelisting. While it provides utility for internal security monitoring, it can produce false positives for high-frequency legitimate crawlers (e.g., search engines, security research scanners).

We strongly recommend implementing ASN-based filtering or User-Agent whitelisting before enabling the `ABUSEIPDB_API_KEY` in production.

If you use this tool to generate datasets for publication, we recommend excluding reporting metadata. Automated reports may propagate inaccurate reputation signals to the community, and we advocate for focused behavioral analysis over generic API reporting.

## Quick Start

### Prerequisites

-   Python 3.10 or newer
-   Poetry (Python dependency manager)

### Installation

1.  Clone the repository:

```bash
    git clone https://github.com/t1a0/http-tarpit.git http-tarpit
    cd http-tarpit
```

2.  Install Poetry (if not already installed):

Follow the instructions on the [official Poetry website](https://python-poetry.org/docs/#installation).

3.  Install project dependencies:

```bash
    poetry install --no-dev
```

4.  Configure environment variables:

Optionally create a `.env` file in the project root:

```env
    # Optional: Enable AbuseIPDB reporting (leave empty to disable)
    ABUSEIPDB_API_KEY=YOUR_ABUSEIPDB_API_KEY
```

5.  Set up GeoIP databases:

*   Download the free `GeoLite2-City.mmdb` and `GeoLite2-ASN.mmdb` databases from [MaxMind](https://www.maxmind.com/en/geolite2/signup).
*   Create a `data/` directory in the project root (if it doesn't exist).
*   Place the downloaded `.mmdb` files into the `data/` directory.


The database (`data/tarpit_events.db`) and its table will be created automatically on the first run if the DB file doesn't exist.

### Running the tarpit 

To start the HTTP tarpit, execute the following command from the project root:

```bash
    poetry run python main.py
```
